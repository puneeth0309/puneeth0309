## Featured Projects

### Multi-Document Conversational RAG System

An intelligent document-assistant application that lets users upload multiple PDFs and ask context-aware questions using Retrieval-Augmented Generation.

- Built a complete RAG workflow covering document loading, chunking, embeddings, semantic retrieval and answer generation
- Added MMR retrieval and BGE reranking to improve the relevance of retrieved context
- Implemented streaming responses, source attribution and multiple retrieval modes
- **Technologies:** Python, Streamlit, LangChain, ChromaDB, Hugging Face, BGE Reranker and Groq LLM

### Medical Chatbot using RAG and Llama

A domain-focused conversational assistant that retrieves relevant medical information before generating concise, context-grounded answers.

- Developed a RAG pipeline using LangChain and Pinecone for semantic document retrieval
- Used Hugging Face embeddings to convert document chunks and user questions into vectors
- Integrated a Llama model through Groq for fast response generation
- Built the application backend with Flask and included source-grounded response handling
- **Technologies:** Python, Flask, LangChain, Pinecone, Hugging Face and Llama
